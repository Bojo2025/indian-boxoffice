How to read this Ramayana main page

Indian Box Office is an independent consensus desk. Figures are weighted-median estimates across trade reports where available. There is still no official Indian theatrical auditor.

  • India nett — domestic after entertainment tax / GST conventions used by trade.
  • India gross — domestic before those deductions.
  • Overseas — outside India only.
  • Worldwide — lifetime consensus gross; daily worldwide is shown only when the ledger publishes it.
